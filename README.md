# Certifications

This repository contains certificates that document completed Data Analytics training.

It serves as a **qualification-evidence repository**, not as a data-analysis portfolio project.

## IBM Data Analyst Professional Certificate

**Issuer:** IBM via Coursera  
**Completed:** February 2026

The Professional Certificate consists of 11 courses covering topics including:

- Data Analytics fundamentals
- Excel for Data Analysis
- Data Visualization and Dashboards
- Python
- SQL and relational databases
- Data Analysis with Python
- Data Visualization with Python
- Capstone project work
- Generative AI for Data Analytics
- Career and interview preparation

## Skills Covered

The program includes practical work with:

- Python
- SQL
- Excel
- Data Visualization
- Dashboard Development
- Exploratory Data Analysis
- Jupyter Notebook
- IBM Cognos Analytics
- Generative AI concepts for analytics workflows
